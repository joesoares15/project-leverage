# Project Leverage roadmap

This is a prioritization guide, not a promise that every idea will be built immediately.

## Active foundation

- GitHub Pages deployment
- Automatic tests and research-data builds
- Sleeper league dashboard
- Cross-league manager identity matching
- Historical rookie/startup draft profiles
- PL-001 AnyRBOnA53 weekly utility
- League-first Portfolio Engine

## Near-term

1. Complete initial GitHub setup and confirm a successful live deployment.
2. Validate PL-001 bundled data and inspect first results.
3. Add reliable historical consensus inputs for draft-reach analysis.
4. Improve manager profiles with cross-league consistency and context normalization.
5. Add transparent architecture metrics without collapsing everything into one contender score.

## Research backlog

- Predictable RB spike weeks
- Minimum viable WR room
- WR top-heaviness versus depth
- RB elevator bench allocation
- Superflex QB leverage
- Productive veteran WR discounts
- Manager-specific draft and trade biases
- Cross-league manager consistency
- Trade timing around injuries and deadlines

## Product backlog

- League-specific opportunity feed
- Trade-partner recommendations
- Portfolio exposure across all leagues
- Research library with versioned methods and confidence levels
- Weekly GM report

## Parking lot

- Asset timeline visualization
- Pick waterfall visualization
- Trade-flexibility score

## Guardrails

- Do not add complexity without a decision it improves.
- Do not present descriptive associations as predictive edges.
- Do not silently rewrite prior research assumptions.
- Do not pay for infrastructure without explicit approval.
