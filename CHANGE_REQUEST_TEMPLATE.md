# Project Leverage change request

```text
Problem or question:

What currently feels wrong, incomplete, or too conventional:

League/player examples, if relevant:

Desired output:

Priority: now / next / research backlog
```

```text
Problem or question:
Can positional injuries predict RB24 weeks better than prior-week touches alone?

Decision this should improve:
Which inexpensive RBs should I roster or start before the market reacts?

What currently feels wrong, incomplete, or too conventional:
The model may be confirming workload after it has already appeared.

League/player examples, if relevant:
Ray Davis behind James Cook.

Desired output:
Show hit rate, precision, recall, and examples for injury-only, workload-only, and combined signals.

Priority: next
```
