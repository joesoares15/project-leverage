# Upload Checklist

Before publishing, confirm:

- [ ] I unzipped the package.
- [ ] I used GitHub Desktop, not browser drag-and-drop.
- [ ] GitHub Desktop shows `.github/workflows/deploy-pages.yml` in the commit.
- [ ] I committed all files to `main`.
- [ ] I published the repository.
- [ ] GitHub Pages source is set to GitHub Actions.
- [ ] The Actions tab shows “Build data and deploy site.”
